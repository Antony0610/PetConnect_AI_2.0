# Comprehensive User & Role Manual - PetConnect AI Ecosystem v2.7.0

Official user operating guide detailing workflows for Pet Owners, Veterinarians, Volunteers, and Administrators.

---

## 📱 1. Pet Owner User Guide
1. **Account Registration**: Select "Pet Owner" role $\rightarrow$ enter profile details $\rightarrow$ verify 6-digit OTP code.
2. **Pet EHR Management**: Navigate to **Health Passport** to add pets, view vaccination schedules, and store medical history records.
3. **Smart Collar Setup**: Navigate to **Smart Collar Setup** $\rightarrow$ enable Bluetooth $\rightarrow$ scan nearby devices $\rightarrow$ enter Wi-Fi credentials to provision hardware.
4. **AI Vision Triage**: Tap **AI Scanner** $\rightarrow$ snap a clear photograph of pet's dermatological skin condition $\rightarrow$ view AI diagnostic report and confidence score.

---

## 🩺 2. Veterinarian Clinical Guide
1. **Clinical Portal**: Access `/vet` route to view today's appointment queue.
2. **Prescription Upload**: Review patient Health Passport EHR $\rightarrow$ attach digital prescriptions and diagnostic notes.

---

## 🤝 3. Volunteer Rescue Guide
1. **Rescue Dispatch Queue**: View active emergency SOS alerts on `/volunteer/rescue`.
2. **Spatial Live Map**: Track real-time GPS locations of lost pets and navigate to rescue site.

---

## ⚙️ 4. Administrator Guide
1. **Command Center**: Monitor global platform telemetry, user account verification status, and collar fleet OTA queues on `/admin`.
