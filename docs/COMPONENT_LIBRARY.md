# Shared Component Library Catalog - PetConnect AI Ecosystem v2.3.0

Catalogue of reusable Material 3 and Glassmorphism Flutter widgets (`lib/src/core/widgets/`).

---

## 🧩 Widget Catalog

1. **`GlassContainer`**: Custom backdrop filter container with blur, gradient border, and translucent fill.
2. **`AIInsightBanner`**: Glowing diagnostic banner with confidence score indicator and call-to-action button.
3. **`PetVitalsCard`**: Smart Collar real-time health metrics card displaying heart rate, body temperature, and battery level.
4. **`RoleSelectorCard`**: Interactive role pick card for onboarding (Pet Owner, Vet, Volunteer, Admin).
