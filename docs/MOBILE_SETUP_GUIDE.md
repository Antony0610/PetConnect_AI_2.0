# Native Mobile Setup Guide (v2.2.0) - PetConnect AI Ecosystem

Official setup guide for building, running, and configuring the **PetConnect AI Native Android Application**.

---

## 📱 1. Prerequisites & Environment

- **Flutter SDK**: `3.22.0` or newer.
- **Android SDK**: API Level 34 (Android 14).
- **JDK Version**: Java 17 LTS.
- **Gradle Version**: `8.0`+.

---

## 🚀 2. Local Android Run Commands

```bash
# Fetch Flutter dependencies
flutter pub get

# Run on connected Android device or emulator
flutter run -d android --release
```
