## 📡 Smart Collar Feature Checklist

- [x] **Bluetooth Device Pairing**: BLE scanning, device discovery, 1-to-1 secret key locking.
- [x] **Wi-Fi Provisioning Wizard**: SSID selection, password setup, connection status verification.
- [x] **GPS Live Tracking**: Real-time coordinates (`lat/lng`), location history, lost pet alert mode.
- [x] **Safe Zone Geofence**: Haversine distance calculation, safe boundary radius, breach SOS broadcast.
- [x] **Firmware & OTA Rollback**: Version tracking, automated update progress, safety rollback log.
- [x] **Strict Scope Guard**: Excludes unauthorized medical sensors (Heart Rate, SpO2, ECG, Blood Pressure).
