# Firebase FCM Push Notification Guide (v2.2.0) - PetConnect AI Ecosystem

Official guide covering Firebase Cloud Messaging integration for mobile emergency SOS alerts, vaccination reminders, and volunteer dispatch notifications.

---

## 🔔 FCM Alert Categories

- **Emergency SOS Alert**: High priority alert with sound & vibration for nearby lost pet reports.
- **Smart Collar Geofence Alert**: Triggered when pet leaves designated safe zone.
- **Vaccination Reminder**: Scheduled alert for upcoming pet immunization.
